
# 🚀 New App

Application web développée avec **React** et **Tailwind CSS**, avec intégration d'une API REST.

## 🛠️ Technologies

* React
* JavaScript
* Tailwind CSS
* REST API
* Git & GitHub

## ✨ Fonctionnalités

* Interface moderne et responsive
* Récupération de données depuis une API
* Affichage dynamique des données
* Gestion des erreurs
* Design responsive avec Tailwind CSS

## 📁 Installation

Cloner le projet :

```bash
git clone https://github.com/amirab123/new-app.git
cd new-app
```

Installer les dépendances :

```bash
npm install
```

Lancer le projet :

```bash
npm run dev
```

L'application sera disponible sur :

```text
http://localhost:5173
```

## 🌿 Git Workflow

Branches utilisées :

```text
main
feature/home
feature/api
feature/ui
```

Exemple :

```bash
git checkout -b feature/home
git add .
git commit -m "Add home page"
git push -u origin feature/home
```
